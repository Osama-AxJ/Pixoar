# texconv.exe

This folder contains `texconv.exe` from Microsoft's DirectXTex project.

- Source: https://github.com/microsoft/DirectXTex
- Release used: `may2026`
- License: included in `DirectXTex-LICENSE.txt`

Pixoar copies this file beside `Pixoar.exe` and `Pixoar.Cli.exe` during build and publish so DDS conversion and DDS previews work without a separate user download.
